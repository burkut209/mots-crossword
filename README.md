# Mots.

An iPad-first multilingual crossword with Turkish, French, Spanish and English, 15×15 /21×21 grids, three difficulty levels, optional clue translations, keyboard and Apple Pencil Scribble entry, local saves and offline play.

Open the published site in Safari, then Share → Add to Home Screen → Open as Web App. Name it Mots. Open from the icon online once and wait for Ready offline.

All game logic and progress stay in the browser. Nicknames and challenge links support informal comparison; there are no accounts or live leaderboards. The finite bank contains 416 dictionary-reviewed entries; words may recur.

To stop public hosting, use this repository’s Settings → Pages → Unpublish site. To remove local game data, use How to play → Remove all local Mots data and clear the site’s browser data. Saved exports and offline installations are separate copies.
